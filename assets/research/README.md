# Research viewer sources

Both figures are reproduced without pixel modifications. CSS displays individual panels using the source-coordinate rectangles in `assets/js/research-data.js`. Labels describing example subjects (e.g. Surfing) are editorial navigation labels, not dataset IDs. No per-subject sample identifiers are inferred.

- `zebra-results.png`: Figure 5, [ZEBRA, arXiv:2510.27128v1](https://arxiv.org/html/2510.27128v1#S4.F5), Haonan Wang, Jingyu Lu, Hongrui Li, Xiaomeng Li. [Original asset](https://arxiv.org/html/2510.27128v1/SOTA_vis.png). The first two columns in each group are Ground Truth and ZEBRA. The other methods are not used in the viewer.
- `vcflow-results.png`: Figure 5, [VCFlow, arXiv:2511.02565v2](https://arxiv.org/html/2511.02565v2#S4.F5), Jingyu Lu, Haonan Wang, Qixiang Zhang, Xiaomeng Li. [Original asset](https://arxiv.org/html/2511.02565v2/results.png). Each group has six published frames; the first two rows are Ground Truth and VCFlow. GLFA rows are not used.

The arXiv HTML pages identify the papers' license as [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Source links appear directly in the viewer. Playback is a slideshow of the six published frames, not an original-rate video, newly generated output, or a model running in the browser. No performance claims are inferred from these illustrative samples.
